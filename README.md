# Loading Screen Gold: A Tip in 200 Characters

A single sharp, funny loading-screen tip for stressed developers and AI coding agents. The program writes one line to `/output/entry.txt`:

> Tip: the agent isn't frozen — it's waiting for you to stop editing the file it's rewriting. Put the keyboard down. Let it cook.

## Run

```sh
node main.ts
```

`OUTPUT_PATH` overrides the output file (default `/output/entry.txt`).
